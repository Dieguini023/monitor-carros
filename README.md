# Monitor Carros

App Android personal que avisa al instante las nuevas publicaciones de carros
(Mercado Libre / TuCarro, por la vía oficial) en la región y el rango de precio elegidos,
y recoge en un solo lugar las alertas de Facebook Marketplace, Mercado Libre y TuCarro.

La APK se compila sola en GitHub Actions con cada cambio y queda en "Releases".
